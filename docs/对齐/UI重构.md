# UI重构需求对齐

## 背景
Magic-Mini 灯珠显示取模工具目前采用基础的 Web UI。为了提升用户体验，使其更符合硬件工具的专业感，需要进行 UI/UX 重构。

## 核心需求
1.  **专业视觉风格**：引入深色模式（Dark Mode），采用科技感色彩方案（如青色/蓝色荧光色）。
2.  **优化布局**：
    -   工具栏：精简操作，突出常用功能。
    -   主工作区：更大、更清晰的灯珠显示，支持更好的视觉反馈。
    -   侧边栏/信息区：集中展示选中的索引数组、状态统计等。
3.  **增强交互**：
    -   灯珠选中时的“发光”效果。
    -   更平滑的过渡动画。
    -   响应式设计，适配不同尺寸的显示器。
4.  **功能保持**：
    -   撤销/重做。
    -   清空/保存/加载。
    -   蛇形连线索引计算。
    -   点击复制。

## 目标用户
硬件开发者、嵌入式工程师、灯效设计师。
