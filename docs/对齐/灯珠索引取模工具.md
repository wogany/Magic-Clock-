# 灯珠索引取模工具 - 对齐文档

## 项目背景
开发一个用于 Magic-Clock 灯珠取模的工具，帮助用户可视化地选择灯珠布局并生成对应的索引数组。

## 需求说明
### 1. 物理布局
- 总计 90 个 WS2812b 灯珠。
- 分为 6 组，每组 15 个灯珠。
- 每组排列：5 行 3 列。
- 组间顺序：从右向左（右边第一组为 Index 0-14，以此类推）。
- 组内顺序：蛇形排列（从右向左、从上到下，每一行方向交替）。

### 2. 功能需求
- **可视化交互**：点击灯珠切换选中状态。
- **实时反馈**：实时显示当前选中的灯珠索引。
- **方案管理**：支持保存当前配置为 JSON/CSV，并能重新加载。
- **操作支持**：支持撤销（Undo）和重做（Redo）。
- **用户引导**：提供操作指引和帮助文档。

### 3. 技术栈
- **前端**：HTML, CSS (Responsive), JavaScript (Vanilla or simple framework).
- **后端**：Python (FastAPI), 使用 `uv` 管理包。
- **数据交互**：RESTful API.

## 约束规范
- 编码：UTF-8.
- 命名：函数小驼峰，宏定义大写下划线，变量名具义。
- 语言：中文。
