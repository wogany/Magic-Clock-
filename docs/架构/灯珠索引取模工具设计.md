# 灯珠索引取模工具 - 架构设计文档

## 系统架构
项目采用前后端分离架构：
- **前端 (Frontend)**: 单页面应用 (SPA)，使用 HTML5, CSS3 (Flexbox/Grid), JavaScript。
- **后端 (Backend)**: FastAPI (Python)，负责索引计算校验、配置存储、导出逻辑。
- **通信**: RESTful API。

## 模块设计
### 1. 前端模块
- **Layout Engine**: 负责 6x15 的灯珠布局展示。
- **Interaction Manager**: 处理点击事件、选中状态维护、Undo/Redo 栈。
- **State Manager**: 管理当前选中的灯珠列表。
- **API Client**: 与后端通信，处理导出和保存。

### 2. 后端模块
- **Calculation Engine**: 核心算法，根据组号、行、列计算全局索引。
- **Storage Service**: 处理 JSON/CSV 的生成与读取。
- **API Router**: 定义接口端点。

## 接口设计 (API Contract)
- `GET /api/config`: 获取当前配置。
- `POST /api/save`: 保存当前配置。
- `GET /api/layout`: 获取灯珠布局信息（颜色、索引等）。

## 数据模型
### 灯珠对象 (Bead)
```json
{
  "id": 0,          // 全局索引 0-89
  "groupId": 0,     // 组号 0-5
  "row": 0,         // 组内行 0-4
  "col": 0,         // 组内列 0-2
  "selected": false // 是否选中
}
```

## 索引计算逻辑
- **全局索引 (Global Index)**:
  - 如果 `R` 为偶数 (0, 2, 4): `I = G * 15 + (R * 3 + C)`
  - 如果 `R` 为奇数 (1, 3): `I = G * 15 + (R * 3 + (2 - C))`
  - 其中：
    - `G` (Group Index): 0 (最右) 到 5 (最左)
    - `R` (Row Index): 0 (最上) 到 4 (最下)
    - `C` (Column Index): 0 (组内最右) 到 2 (组内最左)

## UI 布局草图
- 顶部：标题、操作按钮（保存、加载、导出、撤销/重做）。
- 中间：灯珠显示区域。
  - 6 个卡片（Group），从右向左排列。
  - 每个卡片内 5x3 的圆圈（Bead）。
- 底部：实时选中的索引数组显示、帮助指引。
