# 灯珠索引取模工具 - 原子化任务文档

## 任务列表

### 1. 环境准备 (Env)
- [ ] 初始化 `uv` 项目，安装 `fastapi`, `uvicorn`.
- [ ] 创建项目基础目录结构 (`static/`, `app/`).

### 2. 后端开发 (Backend)
- [ ] 实现 `Bead` 逻辑模型和索引计算算法。
- [ ] 开发导出接口：支持 JSON 和 CSV 格式。
- [ ] 开发保存/加载接口：支持本地文件或内存模拟存储。
- [ ] 实现静态文件服务（挂载前端代码）。

### 3. 前端开发 (Frontend)
- [ ] 编写 HTML 基础骨架：包含控制栏、主显示区、底部信息区。
- [ ] 编写 CSS 样式：使用 Grid 布局 6 个组，每个组内 3x5 布局。实现响应式。
- [ ] 实现交互逻辑：点击灯珠切换状态。
- [ ] 实现 Undo/Redo 状态管理。
- [ ] 实现 API 调用逻辑。

### 4. 集成与测试 (Integration)
- [ ] 前后端联调：验证索引计算准确性。
- [ ] 测试导出功能。
- [ ] 编写操作指引文档。

### 5. 验收 (Assess)
- [ ] 验证 6 组 90 个灯珠的物理布局一致性。
- [ ] 验证索引规则（从右向左、从上到下）。
