# UI重构原子任务

## 任务列表

### 1. 结构重组 (HTML)
- [ ] 修改 `index.html`，建立 `app-container` 结构。
- [ ] 划分为 `app-header`, `app-main`, `app-sidebar`。
- [ ] 在 `app-sidebar` 中预留统计和代码展示区域。
- [ ] 将工具栏按钮移动至侧边栏或页眉。

### 2. 样式升级 (CSS)
- [ ] 更新 `:root` 变量，使用新的深色配色方案。
- [ ] 实现全局深色背景和文字颜色。
- [ ] 重写 `bead` 样式，添加发光和过渡效果。
- [ ] 重写 `group-card` 样式，实现玻璃拟态。
- [ ] 优化 `sidebar` 布局和滚动条样式。
- [ ] 添加响应式媒体查询。

### 3. 交互逻辑适配 (JS)
- [ ] 修改 `script.js` 以适应新的 DOM 结构（如索引显示区域的容器 ID）。
- [ ] 优化复制反馈效果。
- [ ] 确保 Undo/Redo 在新 UI 下工作正常。

### 4. 资源更新
- [ ] 引入新的字体或图标（如果需要）。
