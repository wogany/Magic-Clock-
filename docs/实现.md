# 实现步骤

## 1. 环境初始化
- 使用 `uv init` 初始化环境。
- 安装 `fastapi`, `uvicorn`.

## 2. 后端开发
- 创建 `main.py`。
- 实现 `/api/export` 和 `/api/save/load` 接口。
- 实现静态文件路由，指向 `static/` 目录。

## 3. 前端开发
- `static/index.html`: 结构。
- `static/style.css`: 样式，包含灯珠布局和响应式。
- `static/script.js`: 交互、索引计算显示、Undo/Redo 逻辑。

## 4. UI/UX 重构 (当前)
- 更新 `static/index.html` 为侧边栏布局。
- 更新 `static/style.css` 为深色专业主题。
- 更新 `static/script.js` 适配新结构。

## 5. 验证
- 启动服务 `uv run uvicorn main:app --reload`。
- 访问页面，测试点击、导出功能。
- 检查移动端适配。
