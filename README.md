# Magic-Mini 灯珠显示取模工具 ✨

一个专为 Magic-Mini 硬件项目设计的 LED 灯珠布局可视化与索引取模工具。

---

## 📖 用户指南 (User Guide)

本部分旨在帮助您快速上手并高效使用本工具。

### 1. 它是做什么的？
在开发 LED 矩阵显示程序时，计算灯珠的物理位置与代码索引（Index）的关系往往非常繁琐。本工具提供了一个直观的 Web 界面，让您可以通过“点选”的方式直接获取灯珠索引，并生成可直接用于代码的数组。

### 2. 如何启动？
无需复杂的安装配置，只需：
- 在项目文件夹中找到并 **双击运行 `启动工具.bat`**。
- 脚本会自动检查环境、启动后台服务，并自动在您的浏览器中打开工具页面。

### 3. 主要功能与操作
- **可视化取模**：界面展示了 6 组 LED 模块（Group 0-5），您可以点击任何灯珠来切换选中状态。
- **物理对应**：布局严格遵循硬件接线（Group 0 在最右侧）。
- **一键复制**：右侧会实时生成每组选中的索引数组。点击数组卡片即可自动复制到剪贴板，直接粘贴到您的固件代码中。
- **历史记录**：支持快捷键 **Ctrl+Z (撤销)** 和 **Ctrl+Y (重做)**。
- **保存进度**：点击“保存配置”可将当前的选择存入服务器，下次启动点击“加载配置”即可恢复。
- **自动退出**：当您关闭浏览器页面后，后台服务会自动检测并在 10 秒内停止运行，不会残留后台进程。

## 🛠️ 开发者指南 (Developer Guide)

本部分介绍项目的技术实现细节，供维护或二次开发参考。

### 1. 技术栈选型
- **后端**: [FastAPI](https://fastapi.tiangolo.com/) (Python) - 负责静态文件托管、简单的 JSON 数据存储及服务生命周期管理。
- **环境管理**: [uv](https://github.com/astral-sh/uv) - 用于极速的依赖同步与 Python 环境隔离。
- **前端**: 原生 JavaScript (ES6+) + CSS3 (Grid & Flexbox) - 拒绝繁琐框架，追求极致的加载速度与轻量化。

### 2. 项目结构说明
- **`main.py`**: 后端核心逻辑。包含心跳检测接口、配置保存 API 以及利用 `threading` 实现的浏览器自动开启功能。
- **`static/index.html`**: 页面结构，采用语义化标签。
- **`static/style.css`**: 样式定义。使用了 CSS 变量进行主题管理，并实现了响应式适配。
- **`static/script.js`**: 前端交互逻辑。核心在于**蛇形布局算法**的实现。

### 3. 核心逻辑实现
- **蛇形布局 (Serpentine Layout)**: 
  在 `initLayout` 函数中，通过判断行号的奇偶性来决定局部索引的增长方向，从而匹配硬件的物理接线方式。
- **心跳与自动关闭**:
  前端每 3 秒发送一次心跳请求；后端监测线程持续运行，若心跳中断超过 10 秒则自动安全退出。
- **一键启动脚本**:
  `启动工具.bat` 封装了环境同步与服务启动命令，确保在 Windows 环境下双击即用。

### 4. 本地开发
如果您需要修改代码：
1. 确保安装了 `uv`。
2. 运行 `uv sync` 同步依赖。
3. 运行 `uv run python main.py` 开启开发服务器。
